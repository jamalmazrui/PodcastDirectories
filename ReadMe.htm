Podcast Directories

Podcast Directories is a set of web pages, one for each podcast, that list every public episode of a show along with its key details. Each page is a single HTML file, built to be easy to read and search with a screen reader.

The collection currently covers 154 directories: 114 podcasts and other audio collections with more than 35,000 episodes, 39 old time radio dramas with 5,991 episodes, and a catalog of more than 16,000 free audiobooks.

How to get the pages

Download the whole set as one zip file from this address:

https://github.com/JamalMazrui/PodcastDirectories/archive/main.zip

Unzip it, then open any file that ends in “.htm” in your web browser. Each file is one podcast’s directory.

Why a single page helps

A podcast app shows only a few episodes per screen and asks you to scroll and tap, screen after screen. A show’s own website wraps the same information in menus, players, images, and ads. These pages remove all of that.

With one page per show, you can:

  • Read the whole show from top to bottom, or jump straight to any part.
  • Move by heading with a screen reader. Seasons and topics are level 2 headings, and each episode title is a level 3 heading below them.
  • Search the entire show at once with your browser’s find command.
  • Open any episode with one link that plays it directly. No sign-in is needed.
  • Sort a show by date, by title, or by guest using the appendixes at the end, which most apps do not let you do.
  • Keep the file, read it offline, and open it in any browser.

How each page is built

Every page opens with a table of contents. Episodes are grouped by season or by year, shown as level 2 headings, earliest first, and within each group they are in date order, oldest first, so a show reads the way it unfolded. Each episode title is a level 3 heading whose link plays the episode. Where the show offers a separate details page, an “Episode page” link follows the title. Below each title, the details appear in separate, alphabetically sorted fields, and a field appears only when the information is known:

  • Date — the day it was published.
  • Duration — how long it runs.
  • Episode — its number, when the show uses one.
  • Guests — the people interviewed, for shows that have guests.
  • Season — its season, when that is not already the grouping.
  • Summary — a short description, or the stories and cases the episode covers.

Three appendixes at the end of each page list every episode again in other orders: by date (newest first), by title, and, for interview shows, by guest.

How it was made

Each directory was built from the podcast’s public feed, gathered and organized with heavy use of AI. Only public episodes are included. Some shows keep extra or early episodes behind a paid membership; those are not in a public feed, so the pages list the free episodes.

Old time radio dramas

These are classic radio dramas from the 1930s to the 1960s. A show is included only if it meets all of these rules:

  • Drama: plays and dramatized stories, not comedies, variety shows or music programs.
  • Free source: complete episodes that play free from a public archive, mostly the Internet Archive.
  • No paranormal: no ghosts, curses, the occult or other supernatural events.
  • No science fiction or fantasy: no imagined technology, space travel or magical worlds.
  • Real or realistic: true stories retold as drama, or fiction that portrays its time and place realistically.

Anthologies that mix in supernatural episodes, such as Suspense and Escape, are left out, as are science fiction series such as Dimension X and X Minus One. As a safeguard, fiction episodes whose titles suggest the supernatural are skipped.

The Old Time Radio Dramas page groups the shows by kind: history, realistic crime fiction, realistic drama and adventure, realistic westerns, survival and rescue, and true crime.
