Unobscured Directory

Unobscured, hosted by Aaron Mahnke, is a documentary history podcast whose seasons dig into misunderstood moments such as the Salem witch trials and Jack the Ripper, paired with historian interviews.

This directory covers 72 public episodes, 2018 to 2026. Each episode links to its page and lists the metadata on record, one kind per field, in alphabetical order: Date, Duration, Episode, and Summary, each shown only when available. Titles ignore a leading “A”, “An”, or “The”; people are sorted by surname; all sorting ignores case.

Episodes are grouped by season and, within each group, listed in order by title. Appendixes reorder them by date, by title.

For current details, the linked pages are authoritative. This directory was compiled by Jamal Mazrui from the show’s public feed.
