Casefile True Crime Directory

Casefile True Crime presents meticulously researched accounts of real crimes, told by an anonymous host in a spare, sober style that lets the facts carry the story. Its cases span countries and decades, from solved murders to enduring mysteries.

This directory covers 422 public episodes, 2016 to 2026. Each episode’s title link plays its audio; an Episode page link follows the title when the show offers a separate page; and the metadata on record appears one kind per field, in alphabetical order: Date, Duration, Episode, Season, and Summary, each shown only when available. Titles ignore a leading “A”, “An”, or “The”; people are sorted by surname; all sorting ignores case.

Episodes are grouped by year, earliest first, and within each group they are in date order, oldest first, so a show reads the way it unfolded. Appendixes reorder them by date (newest first), by title.

For current details, the linked pages are authoritative. This directory was compiled by Jamal Mazrui from the show’s public feed.
